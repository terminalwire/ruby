# terminalwire-server

The framework-agnostic [Terminalwire](https://terminalwire.com) server engine —
serve a command-line app to your users' terminals over a single WebSocket, from
any Ruby web stack. For Rails, use [`terminalwire-rails`](https://rubygems.org/gems/terminalwire-rails),
which wires this up for you.

## Documentation

- Rails guide: https://terminalwire.com/docs/rails
- Client manual: https://terminalwire.com/docs/client
- All docs: https://terminalwire.com/docs
